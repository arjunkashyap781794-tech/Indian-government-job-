Create a professional, modern, fast, mobile-friendly website named "All India Govt Jobs" that provides comprehensive information about government jobs, recruitment notifications, admit cards, results, answer keys, admissions, exams, and important documents across India. 1. MAIN CATEGORIES - Latest Government Jobs - Central Government Jobs - State Government Jobs for all Indian states and union territories - SSC Jobs: SSC CGL, CHSL, MTS, GD, CPO and other exams - Railway Jobs: RRB NTPC, Group D, ALP, Technician and other recruitment - UPSC and State PSC examinations - Banking Jobs: IBPS, SBI, RBI and other banks - Police, Defence, Army, Air Force, Navy and paramilitary recruitment - Teaching Jobs: CTET, TET, KVS, NVS and other vacancies - PSU Jobs, apprenticeships, internships and government contractual jobs - Government admissions, entrance exams, scholarships and counselling 2. DEDICATED INFORMATION SECTIONS - Latest Notifications - Online Application Start and Last Dates - Admit Cards - Exam Dates and Exam Schedules - Answer Keys - Results and Merit Lists - Application Status - Syllabus and Exam Patterns - Previous Year Question Papers - Eligibility Criteria and Age Limits - Application Fees and Vacancy Details - Required Documents - Cut-off Marks and Selection Process - Important Forms, Certificates and Official Documents 3. HOMEPAGE DESIGN Create a clean homepage with a top navigation bar, website logo, search box, language selector, latest updates ticker, and clearly organized information sections. Display separate tables or cards for Latest Jobs, Admit Cards, Results, Answer Keys, Admissions and Important Notifications. Every listing should show the post name, recruiting organization, notification date, application deadline, eligibility summary, and current status. Include relevant links such as View Details, Official Notification, Apply Online, Download Admit Card, Check Result and Download Answer Key wherever applicable. 4. SEARCH AND FILTERS Add a search system that lets users search by job title, department, state, qualification, category, organization and application deadline. Add filters for 10th pass, 12th pass, ITI, Diploma, Graduate, Postgraduate, age eligibility and job type. 5. JOB DETAIL PAGES Each job should have a dedicated page containing an overview, important dates, vacancy details, eligibility, age limit, application fee, selection process, syllabus, required documents, official notification link and application link. 6. ADMIN DASHBOARD Create a secure admin dashboard where the website owner can add, edit, publish, schedule and delete job listings, notifications, results, admit cards, answer keys and admissions. Include categories, tags, featured posts, expiry dates, source URLs and publication status. 7. AUTOMATIC UPDATES AND VERIFICATION Design a reliable system to collect and update recruitment information from official government websites and authorized public sources using permitted APIs, RSS feeds or compliant data integrations. Verify information against official sources before publication. Store the original source URL, publication date, last verified date and update status. Never invent vacancies, dates, results, application links or notifications. Clearly mark unverified information and send it for admin review. Do not bypass CAPTCHA, authentication or website access restrictions. If no permitted data feed is available, provide a manual admin workflow and clearly explain the limitation. 8. TECHNICAL REQUIREMENTS Use a modern, maintainable website architecture with a responsive frontend, secure backend, database, admin authentication, server-side validation, SEO-friendly URLs, sitemap, robots.txt, structured metadata and fast page loading. Make the website accessible on Android phones, tablets, laptops and desktop computers. Protect personal information, use HTTPS, secure admin sessions and regular backups. Do not expose API keys or secrets in frontend code. 9. MONETIZATION Keep space for clearly labelled Google AdSense advertisements, subject to approval and applicable policies. Do not use misleading download buttons or intrusive pop-ups. 10. LANGUAGE AND USER EXPERIENCE Support Hindi and English. Use simple Hindi for Indian students. Make the website easy to navigate, even for first-time users. Add About Us, Contact Us, Privacy Policy, Disclaimer, Terms and Conditions and official-source verification information. 11. FINAL DELIVERY REQUIREMENTS Build a functional government jobs information portal, not just a static design. Include a working search, database-backed listings, admin dashboard and a reliable official-source update workflow. Provide sample/demo listings clearly labelled as demo data, not real vacancies. Explain any external API credentials, paid services, hosting, domain or other setup needed to activate each feature. Make sure all important buttons and links work, and show a helpful empty state when no data is available.
